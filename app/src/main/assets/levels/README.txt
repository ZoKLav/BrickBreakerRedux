Built-in stage maps (included in the Android APK).

Levels 1–5 are the earlier Java recreations from the five supplied screenshots.
Levels 6–34 each have a level_XX.txt file here. No import or Internet access
is required. The game reads these automatically when you advance.

IMPORTANT ACCURACY NOTE: These later maps are original-BlackBerry-inspired,
hand-built reconstructions using 2010 written walkthrough descriptions.
They are NOT pixel-verified transcriptions of the linked GIF diagrams.
The source diagrams could not be downloaded during project creation, so some
exact brick coordinates and hit strengths may differ from the original.

Edit each row to adjust a stage before building. Each row has five characters.
  .  empty space
  R  red/brown brick, one hit
  2  two hits
  3  three hits
  4  four hits
  S  gray steel brick, needs Gun to break
The capsules: line is historical metadata only. Remix has randomized drops.
